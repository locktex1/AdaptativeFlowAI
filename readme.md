# AdaptativeFlow AI - Landing Page & Ecosistema EdTech

## 📌 Descripción del Proyecto
**AdaptativeFlow AI** es una startup tecnológica (EdTech) orientada a la *productividad consciente*. Nuestra plataforma sincroniza el rendimiento académico y profesional con el bienestar emocional y físico del usuario.

A diferencia de las herramientas tradicionales basadas en calendarios rígidos, **AdaptativeFlow AI** utiliza Machine Learning e Inteligencia Emocional Artificial para reorganizar dinámicamente las rutinas diarias según el estado de ánimo, los niveles de energía y las métricas biométricas reportadas en tiempo real.

---

## 🤖 Declaración de Herramientas de Inteligencia Artificial
En cumplimiento con los requerimientos del proyecto y los principios de transparencia en el desarrollo digital, se declaran las siguientes herramientas de IA utilizadas:

1. **Gemini (Google AI)**:
   * **Generación de Código**: Utilizado para la escritura, estructuración y optimización del código fuente HTML (`index.html`), hoja de estilos visuales con efecto Glassmorphism (`styles.css`), scripts de animación en Javascript (`script.js`) y la redacción de esta documentación (`README.md`).
   * **Generación de Imágenes**: Utilizado para la creación de la identidad de marca, el logotipo y todos los assets visuales 3D e institucionales (`logo.jpg`, `hero_visual.jpg` y `service_1.jpg` a `service_6.jpg`).
2. **Botpress**:
   * **Desarrollo del Chatbot**: Utilizado para la construcción del asistente conversacional, definición de los flujos de interacción, recomendación automatizada de servicios e integración de sorpresas (cupones, datos curiosos e invitaciones a la app).
   * **Incrustación Web**: Integración del widget flotante de chat mediante script directo en la landing page.

## 🚀 Catálogo de Servicios y Productos
1. **App Móvil de Planificación Dinámica**: Reorganización automática de tareas mediante Machine Learning según picos de energía.
2. **Licencia Institucional "EduFlow"**: Plataforma de monitoreo colectivo e individual del bienestar en colegios y universidades.
3. **Extensión de Trabajo Asíncrono**: Complemento para navegador con gestión de notificaciones y *Focus Mode* para prevenir el burnout.
4. **Módulo Premium de Sincronización Biométrica**: Conexión con smartwatches para analizar variabilidad del ritmo cardíaco (HRV) y niveles de estrés.
5. **Programas de Consultoría en "Productividad Consciente"**: Talleres y coaching B2B para organizaciones e instituciones académicas.
6. **Módulo de Prevención Ergonómica y Pausas Activas**: Sistema inteligente de recomendaciones de descanso según el tiempo de pantalla e indicadores ergonómicos.

## 🛠️ Características Técnicas e Integraciones
* **Diseño Cyan Luxury & Glassmorphism**: Entorno gráfico moderno basado en paleta Cyan (`#D7F6FC`) con desenfoques de fondo (`backdrop-filter`).
* **Tarjetas Giratorias 3D (Flip Cards)**: Módulos interactivos que rotan en versión escritorio mediante *hover* y en versión móvil mediante *tap/click*.
* **Mapa Interactivo Integrado**: Sección *"¿Dónde estamos?"* con iframe de Google Maps ubicado en Ainavillo 456, Concepción.
* **Chatbot Flotante (Botpress)**: Asistente virtual configurado para guiar al usuario e interaccionar de forma automatizada.
* **Diseño 100% Responsivo**: Adaptación fluida para pantallas Desktop XL, Laptops, Tablets y Smartphones.

## 🌐 Guía de Despliegue y Publicación Local
1. Descargar o clonar el directorio `AdaptativeFlow/`.
2. Verificar que la carpeta `images/` contenga todos los archivos con nombres e imágenes `.jpg` exactas.
3. Abrir `index.html` en el navegador para comprobar el funcionamiento local.
4. **Para publicar en internet**:
   * Ingresar a [Netlify Drop](https://app.netlify.com/drop).
   * Iniciar sesión con Google.
   * Arrastrar la carpeta completa del proyecto para obtener el enlace público HTTPS.
