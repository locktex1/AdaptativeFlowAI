# AdaptativeFlow AI - Landing Page & Web Platform

## Descripción del Proyecto
Landing page interactiva y plataforma web para **AdaptativeFlow AI**, diseñada para ofrecer una experiencia orientada a la productividad consciente y sincronización biométrica. La plataforma analiza el estado emocional y nivel de energía del usuario en tiempo real para adaptar su agenda diaria y prevenir el agotamiento (burnout).

---

## 🤖 Declaración de Uso de Herramientas de Inteligencia Artificial

En cumplimiento con los requerimientos del proyecto y las políticas de desarrollo responsable, se declara el uso de las siguientes herramientas de IA:

| Herramienta de IA | Uso / Propósito en el Proyecto |
| :--- | :--- |
| **Gemini (Google)** | Utilizado para la creación de las páginas web, generación de la estructura HTML, estilos CSS, scripts de interacción en JavaScript, y para realizar modificaciones/optimizaciones continuas al código fuente del proyecto. |
| **Botpress** | Utilizado para la construcción, entrenamiento e integración del chatbot conversacional flotante que atiende las dudas de los usuarios y brinda recomendaciones personalizadas en la web. |

## 📦 Productos y Servicios Incluidos

1. **App Móvil de Planificación Dinámica:** Ajuste inteligente de tareas mediante Machine Learning.
2. **Licencia Institucional "EduFlow":** Monitorización del bienestar individual y colectivo para centros educativos.
3. **Extensión de Trabajo Asíncrono:** Complemento de navegador para gestión de notificaciones e integración de modo enfoque.
4. **Módulo Premium de Sincronización Biométrica:** Integración con smartwatches y wearables para medir estrés e indicadores vitales.
5. **Programas de Consultoría B2B en "Productividad Consciente":** Asesorías y workshops para entornos de alta exigencia.
6. **Módulo de Prevención Ergonómica y Pausas Activas:** Notificaciones inteligentes basadas en tiempo de enfoque real.

```text

├── index.html       # Estructura HTML principal de la landing page e integración de la app de IA (Streamlit) y Botpress

└── images/          # Assets de imágenes en formato .jpg
```

## 🚀 Requisitos e Instalación Local

1. Asegúrate de tener todos los archivos (`index.html`, `styles.css`, `script.js`, `README.md`) en la raíz de una misma carpeta.
2. La carpeta `images/` debe contener todas las imágenes citadas con extensión `.jpg` y los nombres exactos para que se muestren correctamente.
3. Para ejecutar la página localmente, simplemente haz doble clic sobre el archivo `index.html` para abrirlo en cualquier navegador web moderno.
